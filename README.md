# 🏠 House Price Prediction Using Linear Regression

## 📌 Project Overview

This project predicts house prices using **Machine Learning** and **Linear Regression**.

The project uses the **Housing.csv** dataset, which contains information about houses such as area, bedrooms, bathrooms, stories, parking, and other facilities.

The main goal is to train a Linear Regression model and predict house prices based on the available features.

---

## 🎯 Objectives

- Load and understand the housing dataset
- Perform basic data analysis
- Check for missing values
- Convert categorical data into numerical form
- Train a Linear Regression model
- Predict house prices
- Evaluate the model using the **R² score**
- Compare actual and predicted house prices visually

---

## 📂 Dataset

The dataset used in this project is:

**Housing.csv**

The dataset contains **545 records and 13 columns**.

### Important Columns

- `price` – House price (Target variable)
- `area` – Area of the house
- `bedrooms` – Number of bedrooms
- `bathrooms` – Number of bathrooms
- `stories` – Number of stories
- `mainroad` – Whether the house is connected to the main road
- `guestroom` – Whether the house has a guest room
- `basement` – Whether the house has a basement
- `hotwaterheating` – Whether hot water heating is available
- `airconditioning` – Whether air conditioning is available
- `parking` – Number of parking spaces
- `prefarea` – Whether the house is in a preferred area
- `furnishingstatus` – Furnishing status of the house
